# Cypress Automation Framework

Automation testing project created using Cypress with Page Object Model and data-driven approach.

## Tech Stack
- Cypress
- JavaScript
- Page Object Pattern
- Fixtures (data-driven tests)

## Covered Areas

### Login Page
- Valid login
- Invalid credentials
- Empty form validation
- Remember Me checkbox

### Contact Form
- Field validation
- Select dropdown
- Checkbox handling
- Invalid email validation

### Edge Case Tests
- Very long input stress test
- SQL injection attempt
- Emoji input handling
- Copy-paste large text simulation
